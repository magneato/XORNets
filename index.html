One gate, ⊕ emulating itself

02 · axn · the champion

Spawn them all. Keep one.

An agent is just its number: its genome is splitmix64(seed + id·φ). Each one wakes up, lives a single life of random bit flips, gets judged by (loss, mutations, id), and is forgotten. Only the champion survives. This arena runs the real algorithm in your browser. The assembly engine does a million agents in 11 seconds.

05 · open a channel

Run it on your machine

Linux x86-64. NASM, binutils and a C++26 compiler. No Python, no downloads, no GPU.

$ git clone https://github.com/magneato/XORNets && cd XORNets
$ ./setup.sh        # nasm · binutils · g++ ≥ 15
$ ./build.sh        # build/xn  build/libxn.a  build/xnc  build/xn_test
$ ./test.sh         # C++26 tests + console checks
$ ./run.sh          # pick a model, watch it learn, talk to it

$ build/xn --help --model models/first-contact.xn
$ build/xn --model models/parity3.xn --agents 1000000
$ build/xn --stats

asm runtime

xor · layer · inference · train · agents · options · model · io · xn. Raw syscalls, mmap'd model files, clone()d threads, futex joins.

c++26 instruments

xnc inspects, forges, sweeps and swarms. xn_test checks the assembly against plain C++ reference code.
